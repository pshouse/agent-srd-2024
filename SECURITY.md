# Security policy

## Reporting a vulnerability

Report vulnerabilities privately with GitHub private vulnerability reporting: **Security tab > Report a vulnerability**.

https://github.com/pshouse/agent-srd-2024/security/advisories/new

Do not open a public issue for a vulnerability.

## Scope

- CLI
- MCP server
- Static site

## Supported versions

The supported version is `main`.

## Response

Response is best effort. There is no committed timeline.

Pages kill switch, 404 checks, and rollback: [docs/SECURITY-PAGES.md](docs/SECURITY-PAGES.md).
